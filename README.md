# 으냉나리 웹사이트 설치가이드

상원여중 대표 마스코트 **으냉나리** 소개 사이트입니다.
- **GitHub Pages**: 사이트를 올리는 곳 (무료, 로그인 없이 링크로 접속)
- **구글 시트와 앱스 스크립트**: 생일 메시지를 저장하는 곳

| 파일 | 하는 일 |
|---|---|
| `index.html` | 메인 사이트 (소개·세계관·친구들·자료실·영상·게임·생일 코너) |
| `admin.html` | 선생님 관리 화면 (학번·이름 확인, 공개/숨김, 간식 추첨, CSV) |
| `js/config.js` | **선생님이 바꾸는 파일**: 웹 앱 주소, 접수 기간 |
| `js/data.js` | 이미지·영상 목록 (이미지를 추가할 때 수정) |
| `apps-script/Code.gs` | 구글 앱스 스크립트에 붙여 넣을 코드 |

---

## 1단계. 구글 시트와 앱스 스크립트 만들기 (10분)

> ⚠️ **학교 구글 계정(Workspace)은 '모든 사용자' 공개 배포가 막혀 있는 경우가 많아요.** 6번에서 '모든 사용자'가 보이지 않으면 **개인 Gmail 계정**으로 처음부터 다시 만들어 주세요.

1. 구글 드라이브에서 **새 구글 시트**를 만들고, 이름을 `으냉나리 생일메시지`로 바꿉니다.
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 원래 있던 코드를 모두 지우고, `apps-script/Code.gs` 내용을 통째로 붙여 넣은 뒤 💾 저장합니다.
4. 왼쪽 ⚙️ **프로젝트 설정**에서 다음 두 가지를 합니다.
   - **시간대**를 `(GMT+09:00) 서울`로 바꿉니다.
   - 아래쪽 **스크립트 속성 → 스크립트 속성 추가**에 두 개를 넣고 저장합니다.

     | 속성 | 값 |
     |---|---|
     | `ADMIN_KEY` | 관리 화면 비밀번호 (8자 이상, 학생이 짐작하기 어렵게) |
     | `TEST_MODE` | `on` (테스트가 끝나면 `off`) |
5. 편집기로 돌아와 위쪽 함수 선택에서 `setup`을 고르고 **▶ 실행**을 누릅니다.
   - 권한 요청 창이 뜨면 계정 선택 → **고급 → (안전하지 않음)으로 이동 → 허용**을 누릅니다. 내가 만든 스크립트라서 나오는 정상 경고예요.
   - 시트에 `메시지` 탭과 머리글(접수시각·학번·이름·메시지·공개·비고)이 생기면 성공입니다.
6. 오른쪽 위 **배포 → 새 배포 → ⚙️ 유형 선택: 웹 앱**을 고르고 다음과 같이 설정합니다.
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
   
   **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 둡니다.

## 2단계. 사이트에 웹 앱 주소 넣기

`js/config.js`를 메모장으로 열고, 복사한 주소를 따옴표 안에 붙여 넣은 뒤 저장합니다.

```js
APPS_SCRIPT_URL: 'https://script.google.com/macros/s/여기에붙여넣기/exec',
```

## 3단계. GitHub Pages에 올리기

1. GitHub에서 **New repository**를 만듭니다. 이름은 예를 들어 `eunnaengnari`로 하고, **Public**으로 둡니다.
2. 파일은 **세 번에 나눠** 올립니다. 한 번에 너무 많이 올리면 실패할 수 있어요. 저장소가 비어 있으면 'Add file' 대신 **uploading an existing file** 링크를 누르세요.
   - ① 첫 번째: `index.html`, `admin.html`, `README.md`, `css`, `js`, `apps-script`를 끌어다 놓고 **Commit changes**
   - ② 두 번째: `assets` 안의 `thumb` 폴더를 잠시 바탕화면으로 옮긴 뒤, 저장소 첫 화면에서 **Add file → Upload files** → `assets` 폴더를 통째로 끌어다 놓고 **Commit changes**
   - ③ 세 번째: 저장소에서 `assets` 폴더로 들어가 **Add file → Upload files** → `thumb` 폴더를 통째로 끌어다 놓고 **Commit changes**
   - 압축 파일(`으냉나리_웹사이트_v6.zip`) 자체를 올리면 안 돼요. 꼭 압축을 푼 안쪽 파일들을 올려 주세요.
3. **Settings → Pages**에서 Branch를 `main`, `/ (root)`로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://내아이디.github.io/eunnaengnari/` 주소로 접속됩니다. 이 링크를 학생과 선생님께 공유하세요.
   - 관리 화면 주소는 `…/eunnaengnari/admin.html`입니다.

## 4단계. 테스트 (11월 4일 전에 꼭 해 보세요)

1. 사이트 주소 뒤에 `?test=1`을 붙여 접속합니다. 예: `…/eunnaengnari/?test=1`
   - 생일 메시지 쓰기 화면이 미리 열려요.
2. 학번·이름·메시지를 넣고 보내 봅니다. 축하 벽에 메시지만 붙는지 확인하세요.
3. `admin.html`에 비밀번호로 들어가서 학번·이름이 보이는지, 추첨이 되는지 확인합니다.
4. 테스트가 끝나면 다음을 정리합니다.
   - 구글 시트에서 '테스트' 행 삭제
   - 스크립트 속성 `TEST_MODE`를 **off**로 변경
